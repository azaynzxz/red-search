# Screenshots Guide

For Chrome Web Store submission, you need high-quality screenshots. Here's how to capture them:

## Required Screenshots (Minimum 1, Maximum 5)

### Screenshot Specifications
- **Size**: 1280x800 or 640x400 pixels
- **Format**: PNG or JPEG
- **Quality**: High resolution, clear and sharp
- **Content**: Show actual extension features

## Recommended Screenshots

### 1. Main View (Hero Shot)
**What to show**: 
- Clean new tab with search bar
- Clock displaying time
- Greeting message
- Pinned apps in dock
- Beautiful background with particles

**How to capture**:
1. Open a new tab
2. Make sure it's a clean state (no widgets open)
3. Set browser window to 1280x800
4. Press F12 → Console → Type: `document.body.style.width = '1280px'`
5. Take screenshot (Windows: Win+Shift+S, Mac: Cmd+Shift+4)

### 2. Widgets Showcase
**What to show**:
- Multiple widgets open (To-Do, Notes, Calculator)
- Show them positioned nicely
- Demonstrate the glassmorphism effect

**How to capture**:
1. Open To-Do widget (add some sample tasks)
2. Open Notes widget (add some sample text)
3. Open Calculator widget
4. Position them nicely on screen
5. Take screenshot

### 3. Pinned Apps
**What to show**:
- Dock with several pinned apps
- Show the hover effect (if possible)
- Include the "Manage Apps" widget open

**How to capture**:
1. Add 4-6 popular apps (Gmail, GitHub, YouTube, etc.)
2. Open the Manage Apps widget
3. Show the grid of apps
4. Take screenshot

### 4. Focus Mode
**What to show**:
- Pomodoro timer running
- Timer circle with progress
- Clean interface

**How to capture**:
1. Open Clock widget
2. Start a Focus session
3. Let it run for a few seconds to show progress
4. Take screenshot

### 5. Completed Features
**What to show**:
- To-Do list with both Current and Completed tasks
- Show the separation between sections
- Demonstrate the feature working

**How to capture**:
1. Open To-Do widget
2. Add several tasks
3. Check off some to move to Completed
4. Take screenshot showing both sections

## Tips for Great Screenshots

### Preparation
- Use a clean browser profile (no other extensions visible)
- Set browser zoom to 100%
- Use sample data that looks professional
- Avoid personal information

### Sample Data Ideas

**To-Do List**:
- "Finish project proposal"
- "Review team feedback"

- "Update documentation"

**Notes**:


**Pinned Apps**:

### Editing Screenshots

After capturing, you can:
1. **Crop** to exact dimensions (1280x800)
2. **Add subtle annotations** (arrows, highlights) if needed
3. **Compress** to reduce file size (keep under 5MB each)
4. **Name clearly**: `screenshot-1-main-view.png`

## Before Uploading

- [ ] All screenshots are 1280x800 or 640x400
- [ ] Images are clear and high quality
- [ ] No personal information visible
- [ ] Sample data looks professional
- [ ] File sizes are reasonable (under 5MB each)
- [ ] Named clearly and numbered
- [ ] Showcase different features in each screenshot

## Upload to Chrome Web Store

1. Go to your extension in the Developer Dashboard
2. Click "Store listing"
3. Scroll to "Screenshots"
4. Click "Add screenshot"
5. Upload your images in order
6. Add captions (optional but recommended)

### Suggested Captions

1. "Beautiful new tab with search and productivity tools"
2. "Multiple widgets for notes, tasks, and calculations"
3. "Pin your favorite apps for quick access"
4. "Focus mode with Pomodoro timer"
5. "Organize tasks with completed section"
