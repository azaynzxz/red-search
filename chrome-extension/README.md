# Search Portal - Premium New Tab Extension

A beautiful, feature-rich Chrome extension that replaces your new tab with a stunning search portal featuring productivity widgets, ambient sounds, and focus mode.

## Features

### 🔍 Smart Search
- Multiple search engines (Google, Bing, DuckDuckGo, YouTube, Wikipedia)
- Quick shortcuts (e.g., `/g` for Google, `/y` for YouTube)
- Beautiful glassmorphism design

### 📱 Pinned Apps
- Add your favorite websites to the dock
- Custom icons support
- Grayscale to color hover effect
- Offline icon caching

### ⏰ Clock Widget
- **Focus Mode (Pomodoro)**: 25/5/15 minute timers
- **Custom Timer**: Set your own countdown
- **Stopwatch**: Track elapsed time
- Visual progress indicator

### ✅ To-Do List
- Add tasks quickly
- Separate "Current Tasks" and "Completed Tasks" sections
- Click to toggle between sections
- Persistent storage

### 📝 Notes
- Quick note-taking
- Auto-save functionality
- Clean, distraction-free interface

### 🎵 Ambient Sounds
- Rain, Cafe, Fire, Wind
- Volume controls
- Multiple sounds can play simultaneously

### 🧮 Calculator
- Full-featured calculator
- Clean, modern design
- Keyboard support

### 🌤️ Weather Widget
- Simple weather display
- City-based lookup

### 🎯 Focus Mode
- Press 'F' to enter focus mode
- Hides all UI elements
- Shows only the clock
- Perfect for concentration

### 🌙 Screensaver Mode
- Activates after 1 minute of inactivity
- Beautiful particle animation
- Large digital clock display

## Installation

### For Development
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" in the top right
3. Click "Load unpacked"
4. Select the `chrome-extension` folder

## Privacy

This extension:
- ✅ Works completely offline after first load
- ✅ Stores all data locally (no cloud sync)
- ✅ No tracking or analytics
- ✅ No external API calls (except for optional weather and app icons)
- ✅ Open source

## Keyboard Shortcuts

- **F**: Toggle Focus Mode
- **Enter**: Submit search or add todo
- **/g + space**: Switch to Google
- **/b + space**: Switch to Bing
- **/d + space**: Switch to DuckDuckGo
- **/y + space**: Switch to YouTube
- **/w + space**: Switch to Wikipedia

## Customization

### Adding Apps
1. Click the "+" icon in the dock
2. Enter the website URL and name
3. Optionally provide a custom icon URL
4. Click "+" to save

### Widgets
- Click any widget icon in the dock to open it
- Drag widgets by their header to reposition
- Multiple widgets can be open simultaneously
- Click the X to close a widget

## Technical Details

- **Manifest Version**: 3
- **Offline Support**: Full PWA capabilities
- **Storage**: LocalStorage for all user data
- **Animations**: Particles.js for background effects
- **Design**: Apple-inspired glassmorphism UI
